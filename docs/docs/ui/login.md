# 로그인과 세션

1. 브라우저에서 UI 개발 서버에 접속합니다.
2. `/login` 화면에서 관리자 계정으로 로그인합니다.
3. 개발 모드 기본 계정은 `admin / admin`입니다.
4. 로그인 성공 시 `/admin/tenants`로 이동합니다.

## 응답 코드 처리

| 응답 | UI 동작 |
| --- | --- |
| `401 Unauthorized` | 인증 상태를 비우고 로그인 화면으로 이동합니다. |
| `403 Forbidden` | 로그인 화면으로 이동하지 않고 권한 부족 안내를 표시합니다. |

:::warning
권한 부족은 세션 만료와 다릅니다. `403`은 현재 로그인한 사용자에게 필요한 권한이 없다는 뜻이므로, 로그인 상태를 유지합니다.
:::
